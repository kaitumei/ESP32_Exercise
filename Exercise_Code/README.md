# 基于ESP32的户外运动数据分析系统

## 项目要求

**要实现的功能：**

1. **主控**：采用 ESP32‑S3 作为主控芯片
2. **传感器采集**
   - GPS：采集地理位置信息
   - 六轴 IMU：采集姿态数据
   - 气压传感器：采集气压，用于解算海拔
   - 心率血氧传感器：采集心率、血氧生理数据
3. **数据存储**：SD 卡本地离线缓存采集到的多维数据
4. **本地显示**：OLED 屏幕实时展示相关数据
5. **通信上传**：Wi‑Fi 联网，将采集数据上传至后端
6. **后端服务（Flask）**
   - 对接上传数据，完成数据持久化存储
   - 根据 GPS 数据实现运动轨迹还原
   - 解算各类运动指标
   - 提供数据可视化功能
